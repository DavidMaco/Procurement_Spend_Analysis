## Skill Definitions

### plan-execute-verify

Use for non-trivial tasks with architectural choices, cross-file changes,
uncertain requirements, or 3 or more meaningful steps.

Protocol:

1. Plan with acceptance criteria and verification gates
2. Execute in scoped increments
3. Verify with evidence
4. Finalize with concise change summary

### standards-review

Use for compliance and quality audits before merge or at completion.

Report structure:

- pass or fail status
- security verdict using the repository rubric
- severity-ordered findings
- evidence references
- required fixes
- advisory improvements
